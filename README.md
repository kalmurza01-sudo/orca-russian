# orca-russian

Русский языковой пакет для [Orca](https://github.com/stablyai/orca).
Устанавливается как плагин: Settings → Plugins → Install from link →
`https://github.com/kalmurza01-sudo/orca-russian`, затем Settings → Appearance → Language → **ru — Русский язык**.
Непереведённые строки автоматически показываются на английском.

Сборка: `python3 tools/pack.py` (батчи из `work/ru/*.json` → `locales/ru.json`).
